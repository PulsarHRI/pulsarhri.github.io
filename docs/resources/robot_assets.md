# Robot model assets

Robot-level MuJoCo models, meshes, trajectories, and example integrations are distributed with the Pulsar SDK examples workflow.

The examples repository will be available at:

[github.com/PulsarHRI/pulsar-sdk-examples](https://github.com/PulsarHRI/pulsar-sdk-examples)

Before coupling a robot model to AUGUR actuator models, read:

- [Robot modelling](../augur/robot_modelling.md)
- [Co-simulation coupling](../augur/co_sim_coupling.md)

Legacy API 2.0 robot asset downloads remain available in the 2.0.4 documentation version.
