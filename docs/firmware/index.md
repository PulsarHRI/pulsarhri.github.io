# Firmware

Keeping PULSAR actuator firmware up to date can provide bug fixes and functionality
improvements. Firmware releases and compatibility vary by actuator model; review
the release details before installing an update.

## Check for and access an update

The [Pulsar App](https://app.pulsarhri.com/) checks whether a newer firmware
release is available and directs you to the current
[firmware update portal](https://mes.pulsarhri.com/update/). You can also open
the update portal directly.

The CAN adapter is supported for the firmware update flow only; this does not
indicate support for other Pulsar App features or normal actuator control over
CAN.

!!! note "Compatibility"
    Firmware availability and compatibility depends on your PULSAR actuator
    model. Follow the instructions provided on the update portal as it automatically enforces this.
