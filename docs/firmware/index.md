# Firmware

Keeping your PULSAR device firmware up to date provides bug fixes and functionality improvements. Firmware availability and compatibility vary by actuator model.

## Check for updates

Use the [firmware update portal](https://update.pulsarhri.com) to manage updates for your PULSAR devices. Other parts of the ecosystem will direct you there when an update is available.

!!! note "Compatibility"
    The update portal automatically checks firmware compatibility with your actuator model. Follow the instructions provided there.
