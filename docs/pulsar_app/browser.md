# Browser app

Open Pulsar App at:

[https://app.pulsarhri.com/](https://app.pulsarhri.com/)

## Requirements

- a powered physical PULSE actuator;
- direct USB connection for the quickstart workflow;
- Linux or Windows;
- Chrome or another Chromium-based browser;
- permission for the site to access the connected serial device.

Firefox may not provide the required device behavior and is not recommended.

## First use

1. Complete [Actuator setup](../hardware/actuator_setup.md).
2. Connect the actuator directly by USB.
3. Open Pulsar App.
4. Grant device access when prompted.
5. Select the actuator under **Devices**.

Continue with the [Physical actuator over direct USB with Pulsar App (browser)](../quickstart/pulsar_app.md).
