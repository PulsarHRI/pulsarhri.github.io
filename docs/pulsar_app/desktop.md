# PULSAR Desktop App

The PULSAR Desktop App provides the same one-actuator workflow as the browser app.

## Compatibility

The current desktop package is tested on Windows.

[Download PulsarApp 1.0.0](../assets/desktopApp/PulsarApp-1.0.0.zip)

After extracting and launching the package, follow [Physical actuator over direct USB with Pulsar App (browser)](../quickstart/pulsar_app.md). The guide uses the browser app, but its basic physical USB setup and workflow also apply to the desktop app.

If installation is not required, use the [browser app](browser.md) instead.
