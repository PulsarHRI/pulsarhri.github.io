# Desktop app

The desktop Pulsar App provides the same one-actuator workflow as the browser app.

## Compatibility

The current desktop package is tested on Windows.

[Download PulsarApp 1.0.0](../assets/desktopApp/PulsarApp-1.0.0.zip)

After extracting and launching the package, follow the [GUI quickstart](../quickstart/pulsar_app.md).

If installation is not required, use the [browser app](browser.md) instead.
