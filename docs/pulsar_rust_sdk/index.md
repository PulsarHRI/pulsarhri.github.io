# Pulsar Rust SDK

!!! info "Coming soon"
    Pulsar Rust SDK documentation and examples are being prepared.

The Rust SDK is intended to follow the same user-facing architecture as the Pulsar Python SDK, including execution domains, physical and virtual actuators, groups, platforms, lifecycle, telemetry, diagnostics, and recovery.

Installation commands, crate links, examples, and the Rust API reference will be added when the package is released.

For current development, use [Pulsar Python SDK](../sdk/index.md).
