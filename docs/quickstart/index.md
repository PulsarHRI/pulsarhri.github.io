# Quickstarts

Choose the shortest path for the system you want to use.

| Setup | Recommended quickstart |
| --- | --- |
| One physical actuator, no code | [One physical actuator · direct USB · Pulsar App (browser)](pulsar_app.md) |
| One physical actuator, Python | [One physical actuator · direct USB · Python SDK](sdk_usb.md) |
| Several physical actuators on CAN FD | [Multiple physical actuators · CAN FD · Python SDK](sdk_can.md) |
| No physical hardware | [Virtual actuators · Python SDK](sdk_virtual.md) |

!!! warning "Physical motion"
    Before using a physical-actuator quickstart, secure the actuator, keep its operating area clear, and know how to remove power safely. Read [Safety and prerequisites](../hardware/safety.md).
