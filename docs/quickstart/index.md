# Quickstart

Choose the shortest path for the system you want to use.

| Setup | Recommended quickstart |
| --- | --- |
| One physical actuator, no code | [Single actuator with Pulsar App](pulsar_app.md) |
| One physical actuator, Python | [Single actuator with Pulsar Python SDK](sdk_usb.md) |
| Several physical actuators on CAN FD | [Multiple actuators with Pulsar Python SDK](sdk_can.md) |
| No physical hardware | [Virtual actuator with Pulsar Python SDK](sdk_virtual.md) |

!!! warning "Physical motion"
    Before using a physical-actuator quickstart, secure the actuator, keep its operating area clear, and know how to remove power safely. Read [Safety and prerequisites](../hardware/safety.md).
