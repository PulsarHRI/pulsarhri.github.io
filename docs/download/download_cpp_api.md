# Download C++ API

## Available Packages

PULSAR HRI provides the C++ API in two Linux package formats for both **x86_64 (AMD64)** and **ARM64 (AArch64)** platforms.

### AMD64 (x86_64)

| Package | Recommended for | Download |
|---|---|---|
| Debian package | Ubuntu/Debian users | [pcp-api-cpp-2.0.0-linux-x86_64.deb](pcp-api-cpp-2.0.0-linux-x86_64.deb) |
| Tarball SDK | Manual/custom installation | [pcp-api-cpp-2.0.0-linux-x86_64.tar.gz](pcp-api-cpp-2.0.0-linux-x86_64.tar.gz) |

### ARM64 (AArch64)

| Package | Recommended for | Download |
|---|---|---|
| Debian package | Ubuntu/Debian users | [pcp-api-cpp-2.0.0-linux-aarch64.deb](pcp-api-cpp-2.0.0-linux-aarch64.deb) |
| Tarball SDK | Manual/custom installation | [pcp-api-cpp-2.0.0-linux-aarch64.tar.gz](pcp-api-cpp-2.0.0-linux-aarch64.tar.gz) |

If you are unsure which package to download, determine your system architecture by running:

```bash
uname -m
```
