# Hardware

Use this section to prepare a physical PULSE actuator before controlling it with Pulsar App or Pulsar SDK.

## Start safely

1. Read [Safety and prerequisites](safety.md).
2. Review the [mechanical](mechanical_interfaces.md) and [electrical](electrical_interfaces.md) interfaces.
3. For a shared DC bus or an application that may return energy, review [Regenerative energy management](regenerative_energy_management.md) before selecting or energizing the power system.
4. Follow [Actuator setup](actuator_setup.md).
5. Choose a method through the [Connectivity overview](connectivity/index.md), then follow the [USB](connectivity/usb.md) or [CAN FD](connectivity/can.md) guide.
